# Flaw Finder

**Category:** Education  
**Package:** `com.mohithash.byok.flawfinder`  
**Short description (≤80):** LSAT logical reasoning, argument by argument

## Full description
Flaw Finder drills LSAT Logical Reasoning by question type, maps any stimulus into premises, conclusion and gap, teaches the flaw catalogue the test reuses, translates conditional statements and their contrapositives, and paces a 35-minute section.

WHAT'S INSIDE
• Logical Reasoning drill — Exam-format questions on one type
• Map an argument — Paste a stimulus → conclusion, premises, gap
• Flaw catalogue — How the test phrases each flaw
• Conditional logic — Diagram it, flip it, chain it
• 35-minute section plan — Checkpoints, two passes, skip rules

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
