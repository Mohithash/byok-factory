# Meeple Studio

**Category:** Games  
**Package:** `com.mohithash.byok.meeplestudio`  
**Short description (≤80):** Design, balance and pitch your own board game

## Full description
Meeple Studio is a board-game designer's workshop: it turns a theme into a core loop, checks the maths behind your economy, writes rulebook sections, digests playtest feedback and specs components for print-and-play or a publisher pitch.

WHAT'S INSIDE
• Design the core loop — Theme → mechanics
• Balance check — Costs, curves, dominant strategies
• Write a rulebook section — Clear, ordered, example-driven
• Digest playtest feedback — Notes → actionable changes
• Components & pitch — Spec, cost, sell sheet

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
