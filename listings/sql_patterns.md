# SQL Patterns

**Category:** Tools

## Full description
SQL Patterns writes the analyst queries that are hard to get right, such as cohort retention, funnels, window functions and date spines, and sanity-checks your query for fan-out joins, NULL traps and timezone bugs.

WHAT'S INSIDE
• Cohort retention — Retention by signup cohort
• Funnel query — Ordered steps with conversion
• Window function coach — Running totals, ranks, gaps, lags
• Sanity-check my query — Fan-outs, NULLs, double counts
• Dates & gaps — Date spines, fill-forward, period-over-period
