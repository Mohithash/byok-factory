# Zettel Loop

**Category:** Productivity  
**Package:** `com.mohithash.byok.zettelloop`  
**Short description (≤80):** Atomic notes that link up and write your essays

## Full description
Zettel Loop runs a Zettelkasten slip-box with you: it turns highlights into atomic notes, proposes links with reasons, writes literature notes and assembles drafts from what you already know.

WHAT'S INSIDE
• Highlight → notes — Split a passage into atomic notes
• Find links — Where does this note connect?
• Literature note — Read → what the author claims
• Draft from notes — Notes → essay outline
• Slip-box review — Weekly health check

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
