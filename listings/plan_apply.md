# Plan Apply

**Category:** Tools  
**Package:** `com.mohithash.byok.planapply`  
**Short description (≤80):** Terraform modules, plans and state, without the fear

## Full description
Plan Apply writes Terraform and OpenTofu modules, explains what a plan will really change, guides state surgery like imports and moves, reviews code for cost and security and resolves drift.

WHAT'S INSIDE
• Write a module — Resource → module with variables
• Explain this plan — plan output → what really changes
• State surgery — Import, move, rename, split state
• Review for cost & security — HCL → findings before the PR
• Resolve drift — Reality differs from the code

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
