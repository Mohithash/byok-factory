# Type Foundry

**Category:** Tools  
**Package:** `com.mohithash.byok.typefoundry`  
**Short description (≤80):** TypeScript errors decoded, types designed, JS migrated

## Full description
Type Foundry decodes TS2xxx errors, designs precise types and generics, writes runtime validators that match them, migrates JavaScript files safely and tunes tsconfig for strictness.

WHAT'S INSIDE
• Decode an error — TS2345 → what it means and the fix
• Design the types — Domain → discriminated unions, generics
• Types meet runtime — One schema → validator and type
• Migrate a JS file — JavaScript → TypeScript safely
• Tune tsconfig — Flags explained, strictness roadmap

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
