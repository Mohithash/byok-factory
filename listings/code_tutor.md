# Code Tutor

**Category:** Education  
**Package:** `com.mohithash.byok.codetutor`  
**Short description (≤80):** Learn to code with a patient mentor

## Full description
Code Tutor explains concepts, reviews your code, debugs errors from screenshots and sets daily practice — in Python, JavaScript, Kotlin and more.

WHAT'S INSIDE
• Explain a concept — With a tiny example
• Debug this — Paste code or a screenshot
• Review my code — Honest, kind, specific
• Daily challenge — 15 minutes

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
