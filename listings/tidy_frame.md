# Tidy Frame

**Category:** Tools  
**Package:** `com.mohithash.byok.tidyframe`

## Full description
Tidy Frame writes and fixes pandas or polars transformations, builds cleaning plans from a data sample, decodes tracebacks and turns chart descriptions into plotting code.

WHAT'S INSIDE
• Write the transform — Columns + goal → code
• Decode a traceback — Paste the error, get the fix
• Clean my dataset — Paste df.head() / df.info() → plan + code
• Chart it — Describe the plot, get the code
• Speed it up — Slow cell → fast cell
