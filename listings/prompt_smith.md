# Prompt Smith

**Category:** Tools  
**Package:** `com.mohithash.byok.promptsmith`  
**Short description (≤80):** Write better prompts for any AI

## Full description
Prompt Smith turns rough asks into structured prompts, critiques your prompts, builds reusable templates and explains why outputs went wrong.

WHAT'S INSIDE
• Improve my prompt — Paste it
• Build from a goal — Describe the outcome
• Why did it fail? — Paste prompt + bad output
• Template library — For your use case

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
