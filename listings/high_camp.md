# High Camp

**Category:** Sports  
**Package:** `com.mohithash.byok.highcamp`  
**Short description (≤80):** Acclimatise, pack and turn around on time

## Full description
High Camp plans alpine and expedition climbs: acclimatisation schedules built from the altitude profile, gear lists by route grade and season, weather-window and turnaround decisions, rope and glacier skills refreshers, and a plain guide to altitude illness.

WHAT'S INSIDE
• Acclimatisation plan — Sleep low, climb high, on paper
• Gear for the route — By grade, season, style
• Summit push window — Multi-day forecast → which day, which camps
• Skills refresher — Rope, anchors, crevasse, self-arrest
• Altitude illness guide — AMS, HAPE, HACE in plain words
