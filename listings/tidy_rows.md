# Tidy Rows

**Category:** Tools  
**Package:** `com.mohithash.byok.tidyrows`  
**Short description (≤80):** Messy exports into clean, trustworthy data

## Full description
Tidy Rows turns messy CSV exports into clean data: it diagnoses what's wrong, writes the cleaning recipe for your tool, designs validation rules and merges duplicate records without losing information.

WHAT'S INSIDE
• Diagnose my data — Paste a sample → every problem
• Write the cleaning recipe — Steps, formulas or code for your tool
• Dedupe rules — Merge duplicates without losing data
• Validation rules — Stop bad data at the door
• Untangle a layout — Human-formatted sheet → tidy table

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
