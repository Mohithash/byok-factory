# Fieldwork Kit

**Category:** Education  
**Package:** `com.mohithash.byok.fieldworkkit`  
**Short description (≤80):** Surveys, interviews and ethics forms that get approved

## Full description
Fieldwork Kit helps student researchers design questionnaires, write interview guides, draft ethics applications and consent forms, recruit participants and take a first pass at coding qualitative data.

WHAT'S INSIDE
• Design a questionnaire — Constructs → clean questions
• Interview guide — Opening, core questions, probes, close
• Ethics application — Study → risks, mitigations, attachments
• Info sheet & consent — Participant-facing documents
• Code my transcripts — Excerpts → codes and candidate themes

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
