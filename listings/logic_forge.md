# Logic Forge

**Category:** Education  
**Package:** `com.mohithash.byok.logicforge`  
**Short description (≤80):** Truth tables, K-maps, binary and the circuits behind CPUs

## Full description
Logic Forge builds truth tables, simplifies Boolean expressions with K-maps, converts and explains number representations, designs combinational and sequential circuits from a spec, and drills computer-architecture concepts.

WHAT'S INSIDE
• Truth table & simplify — Expression → table → minimal form
• Number representation — Binary, hex, two's complement, IEEE 754
• Design a circuit — Spec → gates or flip-flops
• Architecture explainer — Pipelines, caches, ISA…
• Quiz me — 10 questions on one chapter
