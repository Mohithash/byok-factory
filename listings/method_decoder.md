# Method Decoder

**Category:** Education  
**Package:** `com.mohithash.byok.methoddecoder`  
**Short description (≤80):** Why does school do maths like that? Decoded.

## Full description
Method Decoder explains the methods primary schools teach now — bar models, number lines, partitioning, column methods, grid multiplication, bus-stop division, fraction walls — so you can help with homework without confusing your child.

WHAT'S INSIDE
• Explain a method — A worked example the school way
• Decode this homework — Photo → method and how to help
• My way vs school way — Bridge the two so nobody's confused
• Practice set — Questions in the school format
• What they learn this year — The year's maths in plain English
