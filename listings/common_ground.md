# Common Ground

**Category:** Books & Reference  
**Package:** `com.mohithash.byok.commonground`  
**Short description (≤80):** How the world's traditions answer the same questions

## Full description
Common Ground compares how different faiths and philosophies approach a theme — forgiveness, charity, grief, hospitality — with cited passages, shared ground and honest differences, so you can understand a neighbour, a partner or a text without anyone being sold anything.

WHAT'S INSIDE
• Compare a theme — One question, many traditions
• Read a passage — Context and meaning, in its own tradition
• Understand someone's faith — Basics for a friend, partner or colleague
• Prep an interfaith talk — Run a respectful discussion
• Decode a term — Words you've heard but never asked about
