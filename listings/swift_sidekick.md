# Swift Sidekick

**Category:** Tools  
**Package:** `com.mohithash.byok.swiftsidekick`  
**Short description (≤80):** SwiftUI, concurrency, crashes and App Review, handled

## Full description
Swift Sidekick writes SwiftUI views and SwiftData models, reviews async/await code for actor mistakes, decodes crash logs and Xcode errors, and preps you for App Review.

WHAT'S INSIDE
• Build a view — Describe it (or snap a design) → SwiftUI + preview
• Review my concurrency — async/await, actors, MainActor
• Decode a crash or error — Crash log, Xcode error or console noise
• Design the data model — Entities → SwiftData or Core Data
• App Review prep — Guidelines, privacy manifest, metadata

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
