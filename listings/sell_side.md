# Sell Side

**Category:** House & Home  
**Package:** `com.mohithash.byok.sellside`  
**Short description (≤80):** Price, stage and sell your home for the best price

## Full description
Sell Side helps homeowners price realistically from comparables, stage each room before the photos, write listing copy that gets viewings, choose an agent and weigh competing offers.

WHAT'S INSIDE
• Price it — Comparables → asking price and range
• Stage this room — Photo → fixes before the photographer
• Write the listing — Headline, description, photo order
• Choose an agent — Fees, tie-ins, questions to ask
• Weigh the offers — Price vs certainty vs speed

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
