# PARA Desk

**Category:** Productivity  
**Package:** `com.mohithash.byok.paradesk`  
**Short description (≤80):** Sort every note by when you'll act on it

## Full description
PARA Desk organises a second brain by actionability: it files notes into Projects, Areas, Resources and Archives, distils long notes in layers, and runs the weekly review that keeps the system alive.

WHAT'S INSIDE
• Sort a brain dump — Notes → P.A.R.A.
• Progressive summary — Layered highlights of a long note
• Project kickoff note — Start a project properly
• Weekly review — Reset the system in 30 minutes
• Archive audit — What to retire

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
