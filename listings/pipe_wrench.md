# Pipe Wrench

**Category:** Tools  
**Package:** `com.mohithash.byok.pipewrench`  
**Short description (≤80):** Shell scripts and one-liners you can trust

## Full description
Pipe Wrench writes robust bash and zsh scripts, explains cryptic pipelines flag by flag, reviews scripts for ShellCheck-style hazards, builds awk/sed/jq one-liners and schedules jobs properly.

WHAT'S INSIDE
• Write a script — Goal → robust script with usage
• Explain this command — Pipeline → flag-by-flag breakdown
• Review my script — ShellCheck-style hazard hunt
• One-liner — awk, sed, jq, find, xargs
• Schedule it — cron, systemd timers, launchd

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
