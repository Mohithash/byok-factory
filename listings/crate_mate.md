# Crate Mate

**Category:** Tools  
**Package:** `com.mohithash.byok.cratemate`  
**Short description (≤80):** Borrow errors explained, types designed, crates picked

## Full description
Crate Mate explains borrow-checker and lifetime errors with a working fix, designs idiomatic type models, recommends crates with trade-offs, ports code from other languages and decodes clippy.

WHAT'S INSIDE
• Fix a borrow error — rustc error → why, and the fix
• Design the types — Domain → enums, structs, traits
• Pick crates — Task → crate shortlist with trade-offs
• Port to Rust — Python, Go, C or TS → idiomatic Rust
• Explain clippy — Warnings → what they mean and whether to care
