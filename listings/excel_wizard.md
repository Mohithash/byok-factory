# Sheet Wizard

**Category:** Productivity  
**Package:** `com.mohithash.byok.excelwizard`  
**Short description (≤80):** Spreadsheet formulas explained and written

## Full description
Sheet Wizard writes Excel/Google Sheets formulas from plain English, explains scary ones, fixes errors and designs sheet layouts.

WHAT'S INSIDE
• Write a formula — Describe what you need
• Explain a formula — Paste it
• Fix an error — #REF!, #N/A, wrong result
• Design a sheet — Layout for a task

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
