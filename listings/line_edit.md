# Line Editor

**Category:** Books & Reference  
**Package:** `com.mohithash.byok.lineedit`  
**Short description (≤80):** Fiction prose tightened, sentence by sentence

## Full description
Line Editor works at the sentence level of your fiction: filter words, adverbs, telling, dialogue tags, POV and tense slips, and the first page an agent reads.

WHAT'S INSIDE
• Line edit a passage — Filter words, adverbs, echoes, rhythm
• Show, don't tell — Three ways to show one telling line
• Dialogue tag pass — Said, beats, and cut adverbs
• POV & tense check — Head-hops, slips, filtered perception
• First-page verdict — Would an agent keep reading?

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
