# Test Bench

**Category:** Tools  
**Package:** `com.mohithash.byok.testbench`  
**Short description (≤80):** Tests written, flakes fixed, gaps found

## Full description
Test Bench writes unit and integration tests in your framework, diagnoses flaky tests, plans coverage for a feature, designs test doubles and finds the cases your suite misses.

WHAT'S INSIDE
• Write tests for this — Paste code → tests with edge cases
• Fix a flaky test — Intermittent failure → root cause
• Plan the tests — Feature → test plan with priorities
• Mock it properly — Dependency → test double strategy
• Find coverage gaps — Code + tests → what's missing

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
