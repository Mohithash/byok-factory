# Solder Sense

**Category:** Education  
**Package:** `com.mohithash.byok.soldersense`  
**Short description (≤80):** Read parts, size resistors, debug boards, build projects

## Full description
Solder Sense identifies components from a photo, analyses circuits with the maths shown, picks resistor and capacitor values for real parts, plans breadboard and microcontroller projects, and troubleshoots a board that won't work.

WHAT'S INSIDE
• Identify a component — Photo → part, value, pinout
• Analyse a circuit — Describe or photograph → voltages and currents
• Size a part — LED resistor, divider, RC filter, fuse
• Plan a project — Parts list, wiring, code outline
• It doesn't work — Systematic troubleshooting
