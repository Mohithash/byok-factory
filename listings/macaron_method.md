# Macaron Method

**Category:** Food & Drink

**Short description (≤80):** Full feet, smooth tops, no hollows

## Full description
Macaron Method gives you a weighed recipe for the exact shell count you need in French, Italian or Swiss method, plans flavour and colour sets, and diagnoses cracked, hollow or footless shells from a photo.

WHAT'S INSIDE
• Recipe for N shells — Scaled, weighed, method-specific
• Troubleshoot shells — Photo → cause and fix
• Design a box — Flavour and colour set for an occasion
• Filling formulas — Ganache, buttercream, curd, jam
• Oven test plan — Dial in temperature and time
