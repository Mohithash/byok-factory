# Hook Line

**Category:** Tools  
**Package:** `com.mohithash.byok.hookline`  
**Short description (≤80):** React components, hooks and re-renders, sorted

## Full description
Hook Line writes React components and custom hooks in your conventions, explains why things re-render, picks state management for your app and checks your JSX for accessibility.

WHAT'S INSIDE
• Build a component — Describe it (or snap a mockup) → typed code
• Why does it re-render? — Paste a component, get the culprit
• Extract a custom hook — Turn effect soup into a reusable hook
• Pick state management — Context, Zustand, Redux or server state?
• Accessibility check — JSX → what screen readers will hit

BRING YOUR OWN KEY
Works with Claude (Anthropic) or any OpenAI-compatible endpoint (OpenAI, Groq, OpenRouter, Ollama…). Your key and everything you write stay on your phone; requests go straight from your device to the provider you chose. No accounts, no ads, no analytics.

Every answer is a structured, shareable document with follow-up questions, saved on-device so you can come back to it.
